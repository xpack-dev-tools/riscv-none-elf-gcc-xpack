<details>
<summary>What Git branches are available?</summary>

This project uses multiple branches:

- `master`, not actively used
- `xpack`, containing the latest stable version (default branch)
- `xpack-development`, containing the current development version
- `website`, containing the current website content; pushing to this branch
  automatically triggers publication of the main website
- `development`, containing the current preview website content; pushing to this
  branch automatically triggers publication of the preview website

All development is conducted in the `xpack-development` branch, and
contributions via Pull Requests should be directed to this branch.

When new releases are published, the `xpack` branch is rebased
onto `xpack-development`.
